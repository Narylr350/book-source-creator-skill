# v2.3.0

本版本增加面向社区维护版阅读 App 的 JavaScript 单文件书源目标。默认传统 JSON 流程保持不变，继续兼容原版最后版本和社区维护版。

## 社区版 JavaScript 书源

- 新增显式 `community-js` 目标，产物为 `outputs/<site-slug>/book-source.js`。
- 生成前从目标 App 的 `legado://help/jsHelp` 读取当前 JavaScript 契约，不使用静态副本代替 App 实际能力。
- 通过 App MCP 保存并读回脚本，调试搜索、详情、目录和正文四条链路，再执行 App 校验。
- JavaScript 单文件书源只接受社区版 App MCP 验证，不使用本地 validator、Browser MCP 或 Android Probe 替代最终结论。
- `--keep-source` 可以把验证后的书源保留在 App 中继续人工检查。

## 连接与回修

- 电脑与设备处于可互访的局域网时，可通过 `--url` 或 `LEGADO_MCP_URL` 直接连接 App MCP，不需要 adb。
- 局域网不可达或只通过 USB 连接时，唯一在线 adb 设备会自动建立临时端口转发并在命令结束后清理；多设备环境支持 `--serial`。
- App 要求访问令牌时可通过当前进程的 `LEGADO_MCP_TOKEN` 提供。
- `book-source.js` 在验证阶段修改后，`run` 会按当前文件哈希重新执行 JavaScript 合同检查。
- 旧哈希的 App MCP 报告不会被复用，必须重新完成 App 验证、`record-validation` 和 `deliver`。

## 文档

- README 增加传统 JSON 与社区版 JavaScript 的选择说明和任务示例。
- 新增 `docs/COMMUNITY_JS.md`，说明 App 准备、连接、生成、验证、回修和保留书源的方法。

## 升级说明

- 未明确指定目标时仍生成传统 `book-source.json`。
- `book-source.js` 不保证兼容原版最后版本；只有明确使用支持该能力的社区维护版时选择。
- 旧版 run-state 不进行迁移。已有任务需要按当前版本重新初始化。
- 本项目不提供书源合集、小说内容，也不绕过验证码、付费墙、Cloudflare、DRM 或其他访问控制。
